# ☕ Mini curso de Java desde cero

Repositorio con mis ejercicios y retos del mini curso de Java, desarrollados en **IntelliJ IDEA**. Cada módulo explica un concepto y se practica con retos pequeños.

**Autor:** Isaac Cazales Merino

## 🛠️ Requisitos

- JDK 17 o superior
- IntelliJ IDEA (Community o Ultimate)
- Git (opcional, para clonar el repositorio)

## 📚 Contenido

| # | Módulo | Temas | Estado |
|---|--------|-------|--------|
| 1 | Primer programa | JDK, IntelliJ, `main`, `print` y `println` | ✅ |
| 2 | Variables y tipos de datos | `int`, `double`, `boolean`, `char`, `String`, `final` | ✅ |
| 3 | Operadores y entrada por consola | Aritméticos, comparación, lógicos, `Scanner` | ✅ |
| 4 | Condicionales | `if`, `else if`, `else`, `switch`, `equals()` | 🔄 |
| 5 | Ciclos | `for`, `while`, `do-while`, `break`, `continue` | ⬜ |
| 6 | Métodos | Parámetros, retorno, sobrecarga | ⬜ |
| 7 | Arreglos y `ArrayList` | Declaración, recorrido, listas dinámicas | ⬜ |
| 8 | Clases y objetos | Atributos, constructores, métodos | ⬜ |
| 9 | Encapsulamiento | `private`, getters y setters | ⬜ |
| 10 | Herencia y polimorfismo | `extends`, `super`, `@Override` | ⬜ |
| 11 | Excepciones | `try`, `catch`, `finally`, `throw` | ⬜ |
| 12 | Colecciones | `List`, `Map`, `Set` | ⬜ |
| 13 | Proyecto final | Aplicación de consola integrando todo | ⬜ |

## 🎯 Retos

Cada módulo incluye retos prácticos para reforzar lo aprendido, por ejemplo:

- Calculadora con `switch` y validación de división entre 0
- Conversor de temperatura
- Cálculo de IVA
- Detector de año bisiesto

## ▶️ Cómo ejecutar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/isaaccazalem/<nombre-del-repo>.git
   ```
2. Abre la carpeta en IntelliJ IDEA.
3. Abre cualquier clase y presiona el botón ▶ junto al método `main`.
